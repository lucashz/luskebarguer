# Padrão UTM — TáPronto

Formato: minúsculas, sem acentos, palavras separadas por `_`.

| Campo | Regra | Exemplos |
|---|---|---|
| `utm_source` | Plataforma/origem | `instagram`, `google`, `whatsapp_outbound`, `partner_nome` |
| `utm_medium` | Tipo do canal | `organic_social`, `organic_search`, `outbound`, `referral`, `paid_social` |
| `utm_campaign` | Período + nicho + promessa | `2026q3_hamburgueria_pedido_completo` |
| `utm_content` | Formato + tema + variação | `reel_extra_bacon_v1` |
| `utm_term` | Palavra/segmento, quando aplicável | `cardapio_digital_hamburgueria` |

Exemplo:

`https://taprontomenu.com.br/cardapio-digital-para-hamburgueria?utm_source=instagram&utm_medium=organic_social&utm_campaign=2026q3_hamburgueria_pedido_completo&utm_content=reel_extra_bacon_v1`

Checklist: testar o link; não usar dados pessoais; não alterar nomes durante uma campanha; registrar o link no calendário; usar um `utm_content` por criativo.
