Uso interno

Cadastrar cliente manualmente

Cria uma conta de empresa no SaaS sem passar pelo fluxo público de cadastro. Use para suporte, implantação assistida ou clientes cadastrados pela equipe comercial.

Quando usar? Somente quando você, Admin Master, precisar criar o cliente por ele. Se o cliente se cadastrou em /cadastro, esta etapa não é necessária.

Cardápio do cliente

Criar cardápio ou unidade

Cria o endereço público do cardápio para uma empresa já cadastrada. Uma mesma empresa pode ter várias lojas/unidades.

Exemplo prático Empresa: “Central Burger”. Loja/cardápio: “Central Burger Centro” com link público /central-burger-centro.
